Calamity FM v21.5.7 — Biome Runtime / Render Audit
===================================================
Base: Calamity FM v21.5.6 — Abyss Worldgen Only Hotfix

Goal
----
Audit performance paths that only become active near/in Calamity biomes and laboratories,
without changing enemy spawn balance, boss AI, combat, worldgen layout, ambience density,
or dynamic-lighting behavior.

Runtime/render changes
----------------------
1. Sunken Sea ecology drawing
   - Replaced full marker-list traversal with 32x32-tile spatial buckets.
   - Added whole-biome bounds rejection before visible-marker selection.
   - Visible set only rebuilds after the camera crosses an 8-tile cache cell.
   - Reuses native Vector2 scratch objects instead of allocating two per visible marker/frame.
   - Coral/prism source Rectangles are cached by frame rather than allocated every frame.
   - Texture/source work now happens only after a marker passes spatial culling.
   - Decoration density, frames, flip state and per-visible-marker Lighting.GetColor are preserved.

2. Sunken Sea ecology integrity cleanup
   - Old behavior: every 300 ticks (~5 s), globally, even if the player was nowhere near Sunken Sea.
   - New behavior: every 900 ticks (~15 s), only while the local player is inside Sunken Sea.
   - Normal tile breaks still remove markers immediately through OnAnchorBroken.

3. Sulphurous Sea detail/ambience renderer
   - Precomputes custom schematic cells for each Sulphurous Scrap once when metadata loads.
   - Stops rescanning every schematic palette cell on every visible frame.
   - Reuses the renderer's existing Vector2/Rectangle/origin scratch objects for scraps,
     columns and sulphurous ambience cells instead of allocating native structs per draw.
   - Lighting remains per visible cell; visual content/density is unchanged.

4. Abyss ambience broad-phase
   - Added an overall cached ambience bounds rectangle.
   - When the camera is outside those bounds, the renderer skips visible-bucket selection entirely.
   - Existing atlas, 32x32 buckets, 8-tile visible cache and deterministic mobile LOD are preserved.

5. Abyss Shrine visual system
   - Shrine chest light is still injected every frame when it can affect the visible lighting grid.
   - Off-screen shrine no longer calls Lighting.AddLight at 60 Hz globally.
   - Slow smooth-cell integrity scan moved from every 600 ticks globally to every 1800 ticks
     and only while the shrine is near the camera.
   - Tile callbacks still remove broken shrine cells immediately.

6. Iron Ball overlay
   - Cached overall bounds prevents scanning every stored Iron Ball position while off-screen.
   - Reuses native draw scratch structures for visible Iron Balls.

- Enemy spawn rates/weights from v21.5.5/v21.5.6.

Calamity FM v21.5.1 — Tile / Mining Hotpath Audit
====================================================
Base: Calamity FM v21.5 General Runtime Performance Audit
Purpose: reduce Calamity's contribution to mining/block-break frametime when many other mods hook the same Terraria tile methods.

Evidence from visible_logs (13)
-------------------------------
- No Calamity exception was emitted while blocks were being mined/broken.
- The load contains the same large recipe environment (4009 recipes, vanilla maxRecipes 3600).
- External high-probability mining contributors found in the supplied QoL pack:
  * Miners Dream hooks HitTile.AddDamage. When damage reaches 100 on an ore/whitelisted block it executes VeinMiner.Mine synchronously in that frame, then queues tile removal.
  * Fast Tools sets pick/axe/hammer useTime=3 and useAnimation=15, increasing tile-break frequency.
  * Magic Storage Lite registers one GlobalTile only for chest placement, but its framework gates every generic tile hook on hasGlobalTiles, enabling GetPickaxeDamage, CanKillTile, KillTile, sound, dust and drop hooks even though that tracker only implements OnPlace.

Calamity-side changes
---------------------
1. Per-callback GlobalTile hook capabilities are computed once during ModLoader.OnModLoad.
2. WorldGen/Player/Wiring hooks are now installed only when Calamity has a real override for that exact callback.
   Confirmed absent in current Calamity content and therefore no longer hooked:
   CanPlace, IsReplaceable, KillSound, GetTileDustAmount, MakeTileDust, Slope, PreShakeTree, ShakeTree, MouseOverFar, PreHitWire and HitWire.
3. IronBallPlacedGlobalTile no longer participates in GetPickaxeDamage; its GetMinPick/GetMineResist implementations were provably neutral (0 / 1).
4. Effigy mining fast path rejects non-Stone tiles before shrine-cell lookups.
5. AbyssShrineVisualSystem and RoxShrineVisualSystem use numeric O(1) coordinate maps instead of Array.find in mining/hover/break paths.
6. Boss trophies reject non-240 tiles before system/position lookup.
7. Boss relics reject non-617 tiles before system/position lookup.
8. Thank You Painting rejects non-242 tiles before system/position lookup.
9. Iron Ball rejects non-185 tiles before registry lookup.
10. No boss AI, projectile AI, summon AI, damage, loot, recipes, worldgen, tile protection or drop behavior was intentionally changed.

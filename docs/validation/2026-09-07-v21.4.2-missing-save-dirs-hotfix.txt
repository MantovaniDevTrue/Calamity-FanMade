Calamity FM v21.4.2 — Missing Save Directories Hotfix
=====================================================

Base: Calamity FM Pre-Slime God Boss Audit v21.4.1 NPC Registry Compat

Crash fixed
-----------
PostSetupContent called CheckFiles('Players/', '.plr') and CheckFiles('Worlds/', '.wld').
FileManager.ListFiles() directly called System.IO.Directory.GetFiles() even when the
save directory did not exist. On a clean/missing save folder this raised a native
DirectoryNotFoundException and stopped mod loading.

Fix
---
TL/Core/FileManager.js only:
- ListFiles(path) now returns [] when the path is unsafe or the directory does not exist.
- ListDirectories(path) follows the same contract for consistency and future safety.
- Existing directories still use the same native Directory.GetFiles/GetDirectories calls.
- No try/catch was added.
- No boss, summon, NPC registry, item, projectile, buff, worldgen, damage or balance code changed.

# Development history

This directory explains **how the Calamity FM port changed over time and why each important build exists**.

- `VERSION_HISTORY.md` — chronological build lineage and status of preserved versions.
- `CHANGELOG.md` — notable repository and project changes.
- `entries/` — detailed notes for individual investigations, fixes, regressions, or architectural changes when a separate record is useful.
- `ENTRY_TEMPLATE.md` — template for creating a new detailed history entry.

Historical records should normally be preserved rather than rewritten. If later testing changes our understanding of an old build, append a correction or clarification so the original development context is not lost.

# Intermediate Calamity FM builds

Historical/intermediate `.tl` artifacts preserved for regression comparison.

- Version directory names always keep the complete Calamity FM version number (`v21.5.1`, never `v5.1`).
- These artifacts are historical/testing unless explicitly promoted to `builds/stable/`.
- `v21.3` is intentionally not duplicated here because it is already preserved as the validated stable summon baseline.
- `v21.5.7` is intentionally not duplicated here because it is the current testing build and source snapshot.
- Binary `.tl` files are tracked through Git LFS.
